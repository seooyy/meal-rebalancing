# data 폴더 안내

이 폴더의 파일 일부는 git에 올리지 않는다. 새로 합류한 팀원은 아래를 직접 받아야 한다.

## git에 없는 파일 (직접 확보)

| 파일 | 출처 | 비고 |
| --- | --- | --- |
| `ABP_CONTEST_DATA.csv` | 공모전 주최 측 제공 | 16MB. 242,574행, 2026.01~06 |
| `BCCARD_CODE.xlsx` | 공모전 주최 측 제공 | 업종코드 11건 |

두 파일은 공모전 이용조건에 따라 재배포하지 않는다. 팀 내부에서는 별도 경로로 공유한다.

파일이 맞는지 확인:

```bash
python -c "import hashlib;print(hashlib.sha256(open('data/ABP_CONTEST_DATA.csv','rb').read()).hexdigest())"
# 031c3a5ca96d4873a7b7f17869458e4f2ca3452c45cf4c45ff46baca44058c26
```

```bash

```
