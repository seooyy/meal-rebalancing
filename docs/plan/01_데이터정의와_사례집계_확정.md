## 작업 절차

### 1-1. 코드북 고정

[00_개요와_공통규칙.md](00_개요와_공통규칙.md)의 GENDER_CD·AGE_CD·업종코드 표를 `data/out/codebook_v1.csv`로 저장한다. 다음을 코드로 강제한다.

- `GENDER_CD`를 읽을 때 `str` 타입 고정. 법인은 소문자 `'x'`.
- `TP_BUZ_NO`를 `str` 타입 고정 (선행 0 보존).
- 집단 파생: `일반개인 = {'1','2'}`, `외국인 = {'3'}`, `법인 = {'x'}`.
- 연령 분석용 집합: `{'2','3','4','5','6'}`. 코드 `1`·`x`는 연령 비교에서 제외.

### 1-2. 관측 범위 감사

`data/out/audit_v1.csv`에 다음을 기록한다.

- 월별 행수·금액·건수·지역수 (기대: 6개월 × 255개 지역)
- 시군구별 관측 월수 → 6개월 전체 관측이 아닌 지역 목록
- 시군구×업종 조합별 A기간·B기간 동시 관측 여부

관측량 기준선을 여기서 정한다. 기존 EDA 설정값을 승계하되 일반한식·서양음식 두 업종 기준으로 재검토한다. 두 업종은 건수 규모가 달라(전국 건수 비중 18.86% 대 18.35%로 비슷하나 지역별 편차가 크다) 동일 기준선이 적절한지 업종별로 확인한다.

| 기준 | 기존 EDA 값 | 본 단계 결정 (**A 잠정안**, 팀 동기화 때 확정) |
| --- | --- | --- |
| 조합별 최소 건수 | 500 | 아래 단일 기준으로 통합 |
| 지역별 최소 건수 | 5,000 | **폐기 제안** — 아래 단일 기준으로 통합 |
| 기간별 최소 건수 | 1,000 | **1,000 승계** |

**잠정 기준 (단일 규칙)**: 지역×업종 칸과 지역×업종×집단 칸 모두, `min(A기간 건수, B기간 건수) < 1,000`이면 "관측량 부족"으로 수치를 숨기고 실행 후보를 만들지 않는다. 값은 코드에 박지 않고 `config/rules.yaml`의 설정값으로 둔다.

근거 (상세: `notebooks/A01_관측량_기준선.ipynb`, 검증: `tests/test_review_claims.py`):

| 근거 | 내용 |
| --- | --- |
| 이론 | 건수 n의 우연에 의한 변화율 흔들림 √(2/n)이 분류 밴드 `CNT_BAND` ±5%p보다 작아지는 지점 n > 800 → 1,000 |
| 실측 | 집단 칸 500~1,000건 구간에서 금액 초과분 상위 10%가 326%p. 500 기준이면 이런 극단값이 화면에 뜬다 |
| 비용 | 1,530칸 중 107칸(7%) 제외, B기간 금액의 0.094%, 일반개인 0칸. 4셀은 영향 없음 (최소 7,842건) |
| 5,000 폐기 이유 | 기간별 5,000을 적용하면 울릉군 서양음식(A 3,676건 → B 11,915건)이 숨겨진다. 3,676건의 흔들림은 ±2.3%에 불과해 표본 문제가 아니라 관광 계절성이라는 실제 변화다. 건수 기준으로 실제 변화를 숨기지 않는다 |

한계: 1,000~2,000건 구간은 여전히 흔들림이 커서 규모 게이트(5%)·우선순위 게이트가 한 번 더 거른다. 연령 테이블은 칸이 더 작아 별도 확인이 필요하다. 관광 계절성 표시는 팀 동기화 안건이다.

### 1-3. 4셀 사례 재집계

대상: `미추홀구(인천광역시)`, `이천시(경기도)` × `TP_BUZ_NO ∈ {8001 일반한식, 8006 서양음식}`, A=202601~03(90일), B=202604~06(91일).

**재집계 결과 (원본에서 실측 완료). 미추홀구 일반한식 6개 값은 `docs/project_idea.md` 3절 인용값과 일치했다.**

| 분석 범위 | 지표 | A (2026.1~3) | B (2026.4~6) | 변화 |

| 분석 범위 | 지표 | A (2026.1~3) | B (2026.4~6) | 변화 | 전국 대비 |

전국 서양음식도 건당금액이 −6.39% 빠졌지만, 이천시는 그보다 **4.72%p 더 빠졌다.** 255개 지역 중 4번째로 낮아(하위 1.6%), 전국 공통 흐름만으로는 설명되지 않는 지역 고유의 객단가 문제다.

여기서 할인하면 객단가 하락을 가속한다. 확인할 사항은 메뉴 판매 비중·옵션 선택률·세트 구성이다.

### 1-3-b. 사례 해석 시 공통 주의

- 법인 결제는 4셀 모두에서 +7~22% 증가했으나, 전국 기준선이 일반한식 +46.41% / 서양음식 +34.75%다. **지역 법인 증가는 전국 흐름보다 느리다.** 증가율만 보고 지역 고유 기회로 제시하면 안 된다.
- B기간 금액 비중이 5% 미만인 집단(이천시 서양음식 법인 4.75%, 이천시 한식 법인 2.43%, 미추홀구 한식 법인 3.04% 등)은 실행 후보에서 제외하거나 규모를 병기한다.
- **전국 대비 초과분을 반드시 병기한다.** 4셀 모두 금액·건수가 전국보다 −1~−10%p 뒤처진다. 절대 변화율만 보면 이 사실이 드러나지 않는다.

`docs/project_idea.md` 3절 각주의 "이번 통합 작업에서 원본을 재집계하지는 않았다"는 문장은 **재집계 완료로 수정**한다.

### 1-4. 분해 확인

`일평균금액 변화 ≈ 일평균건수 변화 + 건당금액 변화` (로그 기준)가 성립하는지 확인하고 잔차를 기록한다. 기존 `06_matched_period_decomposition.csv`에서 잔차는 수치오차 수준(1e-14)이었다. 4셀 전부 동일하게 검증한다.

이천시 서양음식은 건수 +10.47%, 건당 −11.11%로 두 성분이 크고 반대 방향이라 분해식 검증에 유용하다. 로더 자체 점검(`python -m src.load`)에서 4셀 최대 잔차 2.08e-16을 확인했다.

### 1-5. 주최 측 질의 발송

1. `CCG_NM`이 가맹점 소재지인가 고객 거주지인가.
2. `GENDER_CD=3`(외국인)의 모집단 정의.
3. `AGE_CD=1`의 연령 범위.
4. 파생 집계의 공유·제출 허용 범위.
