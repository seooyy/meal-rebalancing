## 7-A. 인터뷰 (매장 확보 전에도 가능)

### 목적

효과 검증이 아니다. **입력 부담과 실행 가능성** 확인이다.

### 대상 구성

**일반한식 매장과 서양음식 매장을 모두 포함한다.** 두 업종은 객단가가 3배 이상 차이 나고(36,321원 대 10,630원), 원가 구조와 대안의 효과가 다르다. 한식 매장만 인터뷰하면 서양음식 쪽 입력 부담과 실행 제약을 알 수 없다.

최소 구성: 일반한식 2곳, 서양음식 2곳.

### 확인 항목

1. 대표 메뉴 1~3개의 판매가격
2. 원가 범위 (낮음/기준/높음 — 정확한 값을 요구하지 않는다)
3. 실제 매입단가 보유 여부와 형태
4. 판매량 기록 여부 (POS/수기/없음)
5. 운영 제약: 주방 인원, 추가 조리시간 여력, 좌석 회전, 영업시간
6. 단계 2 진단 결과를 보여주고 이해되는지, 어떤 부분이 안 읽히는지
7. 단계 4 시뮬레이터 입력을 실제로 시켜보고 걸리는 시간과 막히는 지점
8. **결제 1건당 평균 인원** — 카드 데이터의 건당금액을 1인 식사 가격으로 오해하지 않기 위해 필요하다
9. **서양음식 매장 한정**: 밀가루·치즈·버터·올리브유·소스류의 매입단가. 단계 5에서 공개 가격 API가 이 품목들을 커버하지 못하므로, 인터뷰가 유일한 확보 경로다. **우선순위를 높인다.**

### 기록

- 관측/추정/가정 구분을 그대로 기록한다
- 개인정보와 매장 식별 정보는 분리 보관한다
- 인터뷰 대상이 소수이므로 **일반화하지 않는다**

## 7-B. 판매 실험 (참여 매장 확보 후)

### 설계

- **대안 하나만** 선택해 시험한다. 여러 개를 동시에 바꾸면 무엇이 작용했는지 알 수 없다.
- 유사한 **요일·영업시간 조건**에서 비교한다 (예: 평일 점심 4주 전 / 4주 후).
- 기록: 공휴일, 날씨, 지역 행사, 영업시간 차이, 품절 여부.

### 핵심 지표

**매장 전체 일평균 공헌이익.** 메뉴 하나의 판매량이 아니다.

함께 기록하는 항목:
- 추가 노동시간
- 폐기비
- 주문 오류 건수
- 고객 반응 (정성 기록)

### 판단 기준 (사전에 확정)

| 판정 | 조건 |
| --- | --- |
| **유지** | 공헌이익이 개선되고 운영 부담이 허용 범위 이내 |
| **수정** | 주문은 늘었으나 이익이 줄거나 운영 부담이 커짐 |
| **중단** | 사전에 정한 손실 한도 초과 또는 고객 불만 지속 |

**손실 한도와 실험 기간을 실험 시작 전에 숫자로 확정하고 문서에 남긴다.** 진행 중에 기준을 바꾸지 않는다.

### 업종별 실험 설계 차이

| | 일반한식 | 서양음식 |
| --- | --- | --- |
| 객단가 | 높음 (약 36,000원) | 낮음 (약 11,000원) |
| 필요 표본 기간 | 상대적으로 김 | 건수가 많아 짧아도 됨 |
| 할인 1,000원의 타격 | 객단가의 2.8% | 객단가의 9.4% |
| 원가 데이터 신뢰도 | 높음 (농축수산물 API 커버) | 낮음 (밀가루·유제품 미커버) |
| 우선 검증할 대안 | 구성 재설계 | 구성 재설계, 도입비 회수 |

서양음식은 객단가가 낮아 **할인형 대안의 위험이 훨씬 크다.** 손실 한도를 업종별로 따로 정한다.

### 해석 제한

- 공헌이익은 순이익이 아니다.
- **업종이 다른 매장의 실험 결과를 합치지 않는다.** 한식 매장에서 통한 대안이 서양음식 매장에서 통한다는 근거가 되지 않는다.
- **짧은 전후 비교만으로 개선의 인과효과를 확정하지 않는다.** 계절·날씨·행사·경쟁 점포 변화가 동시에 작용한다.
- 매장 1곳의 결과를 서비스 효과로 일반화하지 않는다.
- 필요 판매량 달성 여부는 "조건 충족 여부"이지 서비스가 판매를 늘렸다는 증거가 아니다.

## 7-C. 화면 3 구현

| 영역 | 내용 |
| --- | --- |
| 실험 설정 | 선택한 대안, 기간, 비교 조건, 손실 한도 |
| 일별 입력 | 메뉴별 판매량, 비용, 추가 노동시간, 폐기, 주문 오류 |
| 맥락 기록 | 공휴일·날씨·행사·영업시간 예외 |
| 결과 | 매장 전체 일평균 공헌이익 전후 비교, 필요 판매량 대비 실제 |
| 판정 | 유지 / 수정 / 중단 + 근거 |

입력 부담이 크면 실험 자체가 중단된다. 일별 입력 항목 수를 인터뷰 결과에 맞춰 최소화한다.

## 검증 기준

- [ ] 인터뷰 질문지가 원가 "정확한 값"이 아니라 "범위"를 묻는다
- [ ] 일반한식·서양음식 매장이 모두 인터뷰에 포함됐다
- [ ] 서양음식 매장에서 밀가루·유제품·유지류 매입단가를 확보했거나 실패 사유를 기록했다
- [ ] 결제 1건당 평균 인원을 업종별로 확보했다
- [ ] 손실 한도가 업종별로 따로 정해졌다
- [ ] 시뮬레이터 입력 소요 시간을 실측했다
- [ ] 실험 프로토콜에 손실 한도와 기간이 숫자로 적혀 있다
- [ ] 판정 기준이 실험 시작 전에 확정됐다
- [ ] 결과 화면에 "짧은 전후 비교로 인과효과를 확정하지 않는다" 문구가 있다
- [ ] 공헌이익과 순이익이 구분 표기된다
